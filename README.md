# Headroom

A spatial soundscape mixer inspired by ASMR spatial audio. Drag sound sources around a 2D room; a movable, rotatable listener head renders everything in binaural 3D (HRTF) via the Web Audio API.

- Six procedurally generated ambiences (rain, fire, wind, crickets, stream, whisper) — zero audio files
- Live mic input and per-source audio file upload
- Source automation: orbit around listener, ear-to-ear sweep, slow drift
- Per-source height control, generated room reverb, binaural mix recording/export
- Built-in preset scenes + portable JSON scene files

Run it: open `index.html`, or use the GitHub Pages link below. Headphones required for the HRTF effect.
